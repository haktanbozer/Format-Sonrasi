# Güvenlik Politikası (Security Policy)

## Desteklenen Sürümler

Aşağıdaki sürümler aktif güvenlik güncellemeleri almaktadır:

| Sürüm | Destekleniyor mu? |
|---|---|
| 1.0.x | Evet |
| < 1.0 | Hayır |

## Güvenlik Açığı Bildirimi

Format Sonrası Kurulum Sihirbazı'nda bir güvenlik açığı bulduysanız, lütfen bunu genel bir GitHub Issue olarak açmak yerine sorumlu bildirim ilkelerine uygun şekilde iletiniz:

1. **GitHub Security Advisory:** Projenin GitHub sayfasındaki **Security -> Advisories -> Report a vulnerability** sekmesini kullanarak özel bildirimde bulununuz.
2. Bildiriminizde sorunun türünü, etkilenen bileşeni, yeniden üretim adımlarını (PoC) ve olası etki analizini detaylandırınız.
3. Bildirimler en geç 48 saat içerisinde incelenerek geri dönüş sağlanır ve düzeltme yayınlanana kadar koordineli açıklama süreci yürütülür.
